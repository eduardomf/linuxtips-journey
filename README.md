Repositório centralizado para documentação, manifestos, scripts e laboratórios práticos desenvolvidos durante a trilha de formação da **LinuxTips**. 

O objetivo deste projeto é registrar a evolução técnica e consolidar práticas de Infraestrutura como Código (IaC), orquestração de contêineres e observabilidade cloud-native, servindo como base prática para atuar em ambientes de alta complexidade e apoiar a preparação para certificações avançadas, como a **AWS Certified CloudOps Engineer (SOA-C03)** e **HashiCorp Terraform Associate**.

## 📚 Estrutura da Jornada

A trajetória está dividida em módulos sequenciais. Cada diretório contém seu próprio `README.md` com anotações de estudo, comandos úteis e a resolução dos laboratórios.

| Módulo | Descrição e Tecnologias Foco |
| :--- | :--- |
| [**01. Linux para Cloud Native**](./01-linux-cloud-native) | Fundamentos do SO, gestão de processos, redes e shell scripting. |
| [**02. Docker**](./02-docker) | Conteinerização de aplicações, imagens otimizadas e Docker Compose. |
| [**03. Kubernetes**](./03-kubernetes) | Administração de clusters, manifestos YAML, pods, deployments e services. |
| [**04. Helm**](./04-helm) | Empacotamento de aplicações e gerenciamento de releases no K8s. |
| [**05. Terraform**](./05-terraform) | Provisionamento de infraestrutura (IaC), state management e módulos. |
| [**06. Observabilidade**](./06-observabilidade) | Monitoramento de métricas com Prometheus e centralização de logs com Graylog. |
| [**07. GitOps (ArgoCD)**](./07-gitops-argocd) | Continuous Delivery declarativo e sincronização de estado desejado no cluster. |
| [**08. AWS EKS & ECS**](./08-aws-eks-ecs) | Laboratórios de orquestração avançada de contêineres em nuvem pública (AWS). |
| [**09. CI/CD & Automação**](./.github) | Pipelines automatizados com GitHub Actions. |
